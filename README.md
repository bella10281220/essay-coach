# ✍️ 英语作文错题集（Essay Coach）

完全免费的本地英语作文批改工具：AI 逐句批改你的作文、给出**当前水平版**和**进阶版**两个改写、保留并改造你尝试的复杂句、记录你"想说但不会说"的表达，并周期性生成进步回顾报告。

所有数据保存在本机，批改由**本机 Ollama 模型**（免费）或**在线 API** 完成，隐私不出本机。

---

# 🚀 三步上手（跟着做就行）

## 第 1 步：安装 Ollama（AI 的大脑）

> 跳过这步也可以先启动体验（演示模式），但真正的 AI 批改需要它。

**Windows：**
1. 打开浏览器，访问 **https://ollama.com/download**
2. 点击 **Download for Windows**，下载后双击安装，一路点下一步
3. 安装完 Ollama 会自动在后台运行（任务栏右下角有个羊驼🦙图标）

**macOS：**
1. 访问 **https://ollama.com/download**，下载 **macOS** 版（选你的芯片：Apple 芯片或 Intel）
2. 解压后把 Ollama 拖进「应用程序」，打开它
3. 顶部菜单栏出现羊驼图标即表示在运行

**接着拉取模型**（下载一次，以后不用再拉）：
1. 打开终端：
   - **Windows**：按 `Win + R`，输入 `cmd`，回车
   - **macOS**：`command + 空格` 聚焦搜索，输入 `终端`，回车
2. 在黑窗口里输入下面这行，回车，等待下载完成（约 4.7GB，取决于网速）：

```
ollama pull qwen2.5:7b
```

3. 下载完可以顺手验证一下（会回复一句话就说明 OK）：

```
ollama run qwen2.5:7b "你好，用一句话介绍你自己"
```

> 💡 电脑配置好（显卡显存 ≥16GB）可以换更强的 `qwen2.5:14b` 或 `qwen3:14b`；配置一般就用 `qwen2.5:7b`，够用。

## 第 2 步：安装 Python

检查电脑上有没有：打开终端（方法同上），输入：

```
python --version
```

- 如果显示 `Python 3.x.x` → 已经有了，跳到第 3 步
- 如果提示不是内部命令 / 找不到 → 去 **https://www.python.org/downloads/** 下载安装：
  - **Windows**：安装时**务必勾选 ☑ "Add python.exe to PATH"**（第一屏最下面）！
  - **macOS**：一路下一步即可

## 第 3 步：启动错题集

1. 把整个 `essay-coach` 文件夹**放到你想放的任何位置**（比如桌面），不用装到特定目录——它在哪里，数据就存在它自己的文件夹里
2. 启动，**不用敲任何命令**：
   - **Windows**：双击文件夹里的 **`启动错题集.bat`**
   - **macOS**：双击 **`启动.command`**（第一次可能提示"无法验证开发者"，右键 → 打开 → 打开，只会有这一次）
   - **Linux**：终端里进入文件夹，运行 `./start.sh`
3. 浏览器会自动打开 **http://127.0.0.1:5000** —— 开始用！

> 以后每次想用，都只需要双击那个启动文件，**不用**再装任何东西、不用再拉模型。

# 📖 每天怎么用

1. **写作文**：首页填标题、正文，下方"我想表达但不知道怎么用英文说"想填就填 → 点"保存并提交 AI 批改"
2. **看批改（📝 全文批改）**：整篇原文保持完整，像老师红笔批改一样：
   - 有问题的字词**划掉**（红色删除线），旁边**彩色字**给出修改
   - 🟢 绿色 = 语法改正 · 🟠 橙色 = 更好的表达（**原词不划掉**，划线只针对真正用错的词/语法）
   - **点击任何彩色/划线文字** → 下方展开详细讲解（原句 / 改为 / 为什么）
   - 讲解下方就是**追问框**：对这句有疑问直接输入，AI 结合上下文回答；多处可各自追问、可连续追问，问答永久保存
   - 其他标签页：逐句卡片 / 当前水平版 / 进阶版 / 我想说的话
3. **📚 书架**：改好的文章自动变成书架上的"一本书"，点开就像翻书一样重读修改后的全文（可展开进阶版、跳回批改标注）
4. **💬 我想说（独立工具）**：导航栏随时打开，输入中文 → AI 给 3 种地道说法（口语/书面/高级），收藏进**好句收藏**
4. **进步回顾**：写满一个周期（默认 10 篇，可选 20/30）后，首页点"生成回顾报告"

# 📥 导入（含"已批改对话"整理）

GPT / Gemini 里已经改完的作文？两种方式搬进来：

- **方式一（推荐）**：复制批改内容 → 错题集导航栏点「📥 导入」→ 选"我粘贴的是批改结果"→ Ctrl+V → 点「AI 整理入库」。AI 自动把对话解析成逐句批改 + 词汇 + 双版本的标准错题格式。
- **方式二（书签）**：在 ChatGPT/Gemini 页面**用鼠标把那段批改内容拖蓝（选中）** → 点书签栏的「导入到错题集」。选中后连 Ctrl+C 都不用按。

两种方式都会自动存档；若 AI 整理失败，原始内容不丢，详情页可重试整理。

# 🔖 网页一键摘录（免复制粘贴）

**两种书签，按需用（日常主要用第一种）：**

| 书签 | 用途 |
|---|---|
| 📥 **导入到错题集（已批改）** | 你在 GPT / Gemini 里**已经改完**的对话——选中那段批改内容（原文、改动、理由都在里面）→ 点书签 → 自动存档。打开后点"🤖 用 AI 整理成错题格式"，自动归档为逐句批改 + 词汇 + 双版本，并纳入进步回顾 |
| 📝 存入错题集（待批改） | 在别处写了新的英文，想让错题集的 AI 批改时用 |

书签设置方法（首页有可视化引导和代码）：
1. 浏览器收藏任意网页到书签栏，右键编辑该书签
2. 名称改成「导入到错题集」，网址粘贴首页"🔖 网页一键摘录"卡片里的**导入版**代码
3. 在 ChatGPT / Gemini 页面选中批改内容 → 点书签 → 回错题集打开这条记录 → 点"AI 整理成错题格式"

> ChatGPT / Gemini 网页对话没有公开接口，无法被"实时后台"读取；书签摘录是官方机制下最稳妥的方案，比复制粘贴省事得多。

# ⚙️ 换成在线 API（可选，批改更强）

不想跑本地模型，或想要更好的批改质量：首页 **⚙️ 设置 → 模型来源 → 在线 API**，填 API 地址 + Key + 模型名：

| 服务 | API 地址 | 模型名示例 |
|---|---|---|
| OpenAI (GPT) | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Moonshot (Kimi) | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |

用 API 后就不需要 Ollama 了。Key 只存在你本机数据库里。

# 🔄 连上 GitHub（实时更新，不用每次找我下载）

一次性设置（全程点点鼠标，不用装任何东西）：

1. 打开 **github.com** 注册一个账号（已有就跳过）
2. 登录后点右上角 **+ → New repository**：
   - Repository name 填 `essay-coach`
   - 选 **Private**（私有，只有你能看）
   - 点 **Create repository**
3. 在新仓库页面点 **「uploading an existing file」**：
   - 把错题集文件夹里的**所有文件**拖进网页（`data` 文件夹和 `启动日志.txt` 不要传）
   - 点 **Commit changes**，等上传完成
4. 打开更新脚本的下载地址：
   `https://github.com/你的用户名/essay-coach/archive/refs/heads/main.zip`
   （浏览器能打开并开始下载就说明成功了）
5. 把这个地址填进 `更新错题集.bat`（Windows）或 `update.sh` 里开头的 `DOWNLOAD_URL=` 后面，保存

**以后的更新流程**：我给你新版文件 → 你打开 GitHub 仓库页面 → 点「Add file → Upload files」拖入新文件 → Commit → 双击 `更新错题集.bat` → 自动下载替换、数据自动保留 ✅

> 注：`更新错题集.bat` / `update.sh` 需要电脑装有 curl（Win10 自带；macOS/Linux 自带）。

# 📱 手机上看错题

微信小程序需要企业资质审核，个人做不了；但有**更简单的办法**——手机浏览器直接访问：

1. 手机和电脑**连同一个 WiFi**
2. 双击启动文件启动错题集，启动窗口里会打印一行：
   `📱 手机（连同一 WiFi）访问 → http://192.168.x.x:5000`
3. 手机浏览器打开这个地址即可，界面自动适配手机屏幕，批改页支持**左右滑动翻页**

> 想更像个 App：用手机浏览器打开后 → 分享/菜单 →「添加到主屏幕」，就有一个桌面图标，点开即用。
> 注意：电脑关机/休眠后手机就访问不到了；首次连接如提示防火墙，允许"专用网络"即可。

# ❓ 常见问题

| 问题 | 解决 |
|---|---|
| 双击 .command 提示"无法打开" | 右键它 →「打开」→ 再点「打开」（仅第一次需要）；或终端里运行 `chmod +x 启动.command` |
| 不想看到黑色终端窗口（Windows） | 双击 **`启动错题集（后台）.vbs`**（无任何窗口，服务在后台跑），停止时双击 **`停止错题集.vbs`**；后台模式如果打不开网页，看同目录 `start-log.txt` 排错 |
| VBS 双击报错"缺少对象" | 旧版脚本有中文编码问题，**重新下载最新 zip 覆盖**即可（新版已改为纯英文脚本） |
| 书签拖不进书签栏 | 新版浏览器禁止拖拽 js 代码，正常现象！用 **Ctrl+D → 更多/编辑 → 粘贴代码到网址栏**（详见导入页的图文步骤） |
| 批改一直是演示模式 | 首页 ⚙️ 设置 → 点 **「🔍 测试连接」**：会明确显示 Ollama 是否在线、API 是否可用及失败原因；Ollama 已连接时会**列出你已下载的模型**，点击即可选用 |
| 端口被占用（5000 被别的程序占了） | 用编辑器打开 `app.py`，把最后一行的 `port=5000` 改成 `port=5001` |
| Windows 用了语音输入没反应 | 用 Chrome / Edge 浏览器打开错题集 |
| 想备份数据 | 复制 `data/essays.db` 这一个文件即可 |
