🔖 更省事：书签一键导入（设置一次，永久好用）

为什么拖不进书签栏？新版 Chrome / Edge 出于安全考虑，禁止拖拽 javascript 代码了，所以拖不动是正常的！按下面的「三步设置法」来，30 秒搞定：

  1. 在浏览器里按 Ctrl + D（Mac 按 ⌘ + D）—— 会弹出"添加书签"气泡
  2. 点气泡里的「更多…」/「编辑」按钮，进入书签编辑页
  3. 名称填：导入到错题集；网址栏：先复制下面代码框里的全部代码（点一下自动全选，Ctrl+C），再粘贴进去 → 保存

✅ 以后使用：在 ChatGPT / Gemini 页面用鼠标把批改内容拖蓝（选中） → 点书签栏的「导入到错题集」→ 完成，连 Ctrl+C 都不用按。
