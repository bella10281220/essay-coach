🔖 更省事：书签一键导入（设置一次，永久好用）

为什么拖不进书签栏？新版 Chrome / Edge 禁止拖拽 javascript 代码，拖不动是正常的！按下面的步骤来，30 秒搞定：

  1. 在浏览器里按 Ctrl + D（Mac 按 ⌘ + D）—— 会弹出"添加书签"气泡
  2. 点气泡里的「更多…」/「编辑」按钮，进入书签编辑页
  3. 名称填：导入到错题集
  4. 网址栏：先复制下面代码框里的全部代码（点一下自动全选，Ctrl+C），再粘贴进去
  5. ⚠️ 最关键的一步：浏览器粘贴时会自动删掉开头的 javascript: 这几个字（安全机制）。 请看一眼粘贴后的开头——如果直接就是 (function(){...，说明前缀被删了， 要手动在最前面补打 javascript:（冒号也要），否则点了没有任何反应！
  6. 保存 ✅
🧪 装好了吗？10 秒自检：随便打开一个网页，直接点书签栏的「导入到错题集」—— 页面顶部弹出「⏳ 正在收藏整页…」然后变成绿色 ✅（或红色报错原因），说明书签已装好。 如果完全没有任何提示，就是第 5 步的 javascript: 前缀没补上。

✅ 以后使用：在 ChatGPT / Gemini 的对话页面直接点书签栏的「导入到错题集」——不用选中任何文字， 它会自动找到对话内容最多的区域（通常是整段对话），把正文抓下来。 每一步都有提示条：页面顶部会依次显示「正在收藏…」→「✅ 已收藏（带『去看看』链接）」或红色报错原因，绝不会没反应。

🔄 之前装过旧版书签？如果点书签弹的是「请先在网页中选中要收藏的文字」，说明还是旧版—— 请按上面步骤重新复制下面的新代码、更新书签（旧版只抓选中一小段，新版才抓整页）。
